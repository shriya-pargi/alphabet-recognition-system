# 🔤 Alphabet Recognition System

A deep learning-based system that recognizes handwritten alphabets using an interactive drawing interface.

---

## 🚀 Features
- ✍️ Draw alphabets using a sketchpad
- 🤖 Real-time prediction using CNN model
- 📊 Top-3 predictions with confidence scores
- 🧠 Image preprocessing for improved accuracy

---

## 🛠️ Tech Stack
Python, TensorFlow/Keras, OpenCV, NumPy, Tkinter

---

## ⚠️ Model File

The trained model file (.h5) is not included in this repository due to size constraints.
---

## ⚙️ How it works
- User draws a letter
- Image is preprocessed (thresholding, resizing, normalization)
- Model predicts output
- Top predictions are displayed

pip install -r requirements.txt
